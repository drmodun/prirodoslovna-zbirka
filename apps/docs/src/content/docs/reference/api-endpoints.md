Live, typed documentation is generated by Swagger: **`/api`** on a running
API (http://localhost:5500/api locally, `<PUBLIC_URL>/api/api` behind the
compose proxy, where `/api` is also the proxy prefix). The OpenAPI JSON is at
`/api-json`.

**Auth** column:

- **JWT**: `JwtAuthGuard`, a valid `Authorization: Bearer` token is required.
- **opt.**: `OptionalJwtAuthGuard`, public, but a token changes the answer
  (personalisation, unapproved items for admins).
- **—**: no guard. Further permission checks happen in the handler; see
  [Roles and permissions](/docs/reference/roles-and-permissions/).

Paths are relative to the API root (behind the proxy, prefix them with
`/api`).
