Biosfera (repository `prirodoslovna-zbirka`, "natural history collection") was
built primarily for III. gimnazija Split and the Infokup competition.
Organisations (usually schools) catalogue **exponats**: specimens of
prokaryotes, eukaryotes and minerals. Their members write **posts** about
them, publish **works** (papers, posters, presentations) and **social posts**
(news, events, workshops), and everyone else follows, likes, saves and
discovers.

The user interface is in English and Croatian. These docs are for the people who run,
change and test it.

<CardGrid>
  <Card title="Two apps, one types package" icon="seti:typescript">
    A NestJS API on Postgres (Prisma) and a Next.js 15 app-router frontend,
    sharing DTOs and enums through `@biosfera/types`. Yarn workspaces and
    Turborepo hold it together.
  </Card>
  <Card title="Runs without any accounts" icon="rocket">
    Every external service (S3, mail, AI, text to speech) has a built-in
    fallback. `docker compose up` brings up the whole stack, these docs
    included.
  </Card>
  <Card title="Moderation built in" icon="approve-check">
    Organisation roles decide what is published straight away and what waits
    for an admin. Notifications reach people live over server-sent events.
  </Card>
  <Card title="Three layers of tests" icon="list-format">
    Jest unit tests in both apps, API integration tests against a real
    Postgres, and Playwright end-to-end flows. Known bugs are pinned as
    expected failures.
  </Card>
</CardGrid>
